# Smart Loan Advisor System

An AI-powered Loan Prediction Platform that helps users evaluate loan eligibility, estimate EMIs, compare loan options, and receive intelligent financial recommendations.

## Features

- AI-based Loan Eligibility Prediction
- Explainable AI Recommendations
- Secure User Authentication
- Loan Planner
- EMI Calculator
- Loan History Tracking
- User Profile & Settings
- PDF Report Generation
- Admin Dashboard
- Responsive Professional UI
- Future Support for Real-Time Bank API Integration

## Tech Stack

- Python
- Flask
- Machine Learning (Scikit-learn)
- SQLAlchemy
- SQLite
- HTML5
- CSS3
- Bootstrap
- Chart.js

## Future Enhancements

- Real-Time Bank API Integration
- Live Interest Rate Comparison
- Personalized Loan Recommendations
- Credit Score Analysis
- Email Notifications

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/Smart-Loan-Advisor-System.git

cd Smart-Loan-Advisor-System

pip install -r requirements.txt

python run.py
```
